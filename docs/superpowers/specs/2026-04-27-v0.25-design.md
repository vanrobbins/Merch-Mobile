# v0.25 Interactive Layout Editor — Design Spec

**Date:** 2026-04-27
**Status:** Approved

---

## Overview

v0.25 fixes the incomplete interactive layout experience from v0.2 before moving to v0.3 (mannequins, brand system). Four areas:

1. **Store Canvas** — replaces the static Zone Map with a bounded, editable canvas
2. **Zone interaction** — Figma-style drag-to-move + vertex reshape
3. **Fixture resize + rotation** — type-aware edge handles, rotation via long-press
4. **Planogram assignment** — badge tap → picker sheet; fixture selection → mini-panel with VIEW →

Planogram Editor (create/edit planogram slots) is out of scope — stays in v0.3.

---

## 1. Store Canvas

### What changes
`ZoneMapScreen` currently shows a static zone polygon viewer with no store boundary. v0.25 replaces this with a bounded, interactive canvas.

### Data boundary (critical)
Store Canvas reads **zones table only**. It never reads fixtures. Fixtures live in Floor Builder. This boundary must not be crossed — it prevents duplicated logic as the app grows.

### Store boundary
- New columns: `stores.width_ft REAL` (nullable) + `stores.depth_ft REAL` (nullable)
- On first open, if `width_ft` or `depth_ft` is null, show a one-time setup dialog: two number fields (width, depth in feet), a confirm button. Saves via `StoresDao.updateDimensions(storeId, widthFt, depthFt)`.
- Canvas draws a thick-bordered rectangle at `width_ft × depth_ft`. Zones outside this boundary are still rendered but shown with a warning tint.
- ft grid lines inside the boundary (every 5 ft by default, thinning as zoom decreases).

### Zone interaction (Figma-style)
- **Tap** a zone → selects it (dashed selection outline, vertex handles appear)
- **Drag zone interior** (inside polygon, not on a vertex) → moves entire zone; all vertices translate by delta
- **Drag a vertex handle** → reshapes zone (existing behaviour, already implemented)
- **Tap empty canvas** → deselects
- Hit detection order: vertex handles first (7px radius), then interior polygon.

### Zone selection UI
Selected zone shows:
- Dashed accent-coloured outline
- Filled vertex circles (radius 8, accent fill, white stroke)
- Zone label remains visible
- No separate move icon — drag interior is the move gesture

### Zone navigation
- **Tap unselected zone** → selects it (replaces current tap-to-navigate)
- **Tap already-selected zone** → navigates to `ZoneDetailScreen`
- This gives selection without losing drill-down access

### Unchanged
- ADD ZONE FAB with RoleGuard
- ZoneLegendPanel
- Long-press action sheet (label, delete)

## 2. Fixture Resize — Floor Builder

### Edge handles (type-aware)
When a fixture is selected, render edge-midpoint handles. Which handles are shown depends on fixture type:

| `fixtureType` | Handles shown | Notes |
|---|---|---|
| `rack` | Top, bottom, left, right | Free W + D resize |
| `table` | Top, bottom, left, right | Free W + D resize |
| `wall` | Left, right only | Width only; depth fixed |
| `shelf` | Left, right only | Width only; depth fixed |
| `partition` | Top, bottom, left, right | W + D, but depth capped at 1.0 ft max |

Handle appearance: 18×18 rounded rect, accent fill (`#BF5534`), white arrow glyph (↔ or ↕).

### Resize gesture
- `onPanStart` on a handle → begin resize
- `onPanUpdate` → update `widthFt` or `depthFt` in provider state (live preview)
- `onPanEnd` → persist via `fixturesDao.upsert()`
- Minimum size: 0.5 ft on any axis

### Rotation
Stays on long-press action sheet (already implemented). No change to rotation UX.

## 3. Planogram Assignment

### Badge rendering
Every fixture on the Floor Builder canvas renders a small badge at its bottom-right corner:
- **Unassigned:** grey chip, label "—"
- **Assigned:** accent-coloured chip (`#BF5534`), label = truncated planogram name (max 14 chars + "…")

Badge is rendered as a separate `GestureDetector` wrapping a `CustomPaint` or `Container` overlay — it is a distinct tap target from the fixture body.

### Badge tap → picker sheet
Tapping the badge opens `PlanogramPickerSheet` (a `DraggableScrollableSheet`):
- Header: fixture label + current assignment (or "Unassigned")
- Search field (filters planogram list by name)
- Scrollable list of `PlanogramPickerTile` widgets: planogram name, season, slot count
- Tapping a tile → calls `fixturesDao.upsert(fixture.copyWith(planogramId: selected.id))` → sheet closes
- "Remove assignment" option at top of list if currently assigned
- Cancel / drag-down to dismiss

Data: `planogramsDao.watchByStoreId(storeId)` stream feeds the picker.

### Fixture selection → mini-panel
Tapping the fixture body (not the badge) selects it. Selection shows:
- Dashed selection outline on canvas
- `FixtureMiniPanel` slides up from canvas bottom (not full-screen):
  - Dark background (`#1A1917`)
  - Fixture name (ALL CAPS) + dimensions (`4 × 2 ft`)
  - Planogram row: name + `X/Y slots assigned` · if unassigned shows "No planogram"
  - **VIEW →** button → `context.push(AppPaths.planogramDetail(planogramId))` (disabled/hidden if unassigned)
  - Dismiss by tapping canvas background or X button

`FixtureMiniPanel` is a separate widget, not part of `BuilderCanvasPainter`. It overlays the `Stack` in `FloorBuilderScreen`.

## 4. Schema Changes

### `stores` table
Add two nullable real columns:

```dart
RealColumn get widthFt => real().nullable()();
RealColumn get depthFt => real().nullable()();
```

Migration: `schemaVersion` bump to 3, `destructiveFallback` (dev — acceptable).

### `fixtures` table
`planogram_id` already exists per v0.2 spec. No schema change — just UI wiring.

### `StoresDao`
Add `updateDimensions(int storeId, double widthFt, double depthFt)` method.
