### Task 5 — Planogram editor AppBar: add rename edit icon cue

**File:** `lib/features/planogram/planogram_detail_screen.dart`

In the edit-mode AppBar, the title is a `GestureDetector` wrapping `Text(pg.title.toUpperCase())`. Add an edit icon beside the text so the tap target is discoverable:

```dart
// BEFORE:
title: GestureDetector(
  onTap: () => _editTitle(pg.title),
  child: Text(
    pg.title.toUpperCase(),
    style: const TextStyle(color: AppTheme.canvasBg),
  ),
),

// AFTER:

  onTap: () => _editTitle(pg.title),
  child: Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      Flexible(
        child: Text(
          pg.title.toUpperCase(),
          overflow: TextOverflow.ellipsis,
          style: const TextStyle(color: AppTheme.canvasBg),
        ),
      ),
      const SizedBox(width: 4),
      const Icon(Icons.edit_outlined, size: 14, color: AppTheme.textHint),
    ],
  ),
),
```
