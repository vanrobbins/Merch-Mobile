# v0.3 Manager Plan — Merch Mobile VM Merchandising Layer

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Orchestrate 6 agents to deliver v0.3: brand color palettes, product templates, 3-step product form, mannequin placement, mannequin dressing (Mannequin Lock), and scene props/platforms.

**Architecture:** Two phases. Phase 1 has a gate (Agent 1 schema must merge first). After Agent 1 merges, Agents 2, 3, 4 run in parallel. After all Phase 1 PRs merge to main, Agents 5 and 6 run in parallel.

**Prerequisite:** v0.2 fully merged to main. Verify: `git log main --oneline | head -10`

---

## Agent Dependency Map

```
Agent 1 (Schema+Foundation)

         └── Agent 4 (Mannequin Dressing)

```
