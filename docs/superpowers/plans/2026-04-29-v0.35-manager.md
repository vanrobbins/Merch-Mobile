# v0.35 Manager Plan — Parallel Agent Orchestration

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver undo/redo, AutoBuild enhancements, a full planogram editor, and product gender classification across 7 parallel-friendly agents.

**Architecture:** Wave-based parallel execution. Wave 1 (Agents 1–3) share no files and run simultaneously. Agent 4 starts after Agent 3 finishes. Agents 5+7 run in parallel after Agent 4. Agent 6 last.

**Tech Stack:** Flutter, Riverpod 2.5+, Cloud Firestore, GoRouter 14+, @freezed, flutter_svg

**Spec:** `docs/superpowers/specs/2026-04-29-v0.35-design.md`

---

## Dependency Graph

```
Wave 1 (parallel — no shared files):
  Agent 1: Undo/Redo Delta Stack (floor_builder only)
  Agent 2: AutoBuild Enhancements
  Agent 3: Planogram Data Model + PgRow + PgSlot + creation dialog

Wave 2 (after Agent 3 completes):
  Agent 4: PlanogramEditorScreen + route + editor undo

Wave 3 (after Agent 4 completes, parallel):
  Agent 5: SVG Assets (shoulder_out + folded silhouettes)
  Agent 7: Product Gender Classification (Product model + form + catalog + picker)

Wave 4 (after all complete):
  Agent 6: Tests
```
