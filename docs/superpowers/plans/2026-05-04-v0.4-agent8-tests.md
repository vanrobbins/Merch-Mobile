## Context

Add widget smoke tests for the five new shared widgets created in the v0.4 sweep. These widgets have zero test coverage. Tests should verify rendering and interaction, not mock internals.

## Tests to Write

### `test/core/widgets/mm_button_test.dart`
- Filled variant renders accent background
- Outlined variant renders border, transparent background
- Destructive variant renders error color background
- Text variant renders no background, no border
- `isLoading: true` shows CircularProgressIndicator, disables tap
- `onPressed: null` disables the button

### `test/core/widgets/mm_dialog_test.dart`
- `MmDialog.show` renders title and content
- Title displays in ALL CAPS (or passed as-is)
- Actions row renders provided buttons
- Dialog uses surfaceVariant background

### `test/core/widgets/mm_list_tile_test.dart`
- `MmListTile` renders title
- Renders subtitle when provided
- Renders leading when provided
- Renders trailing chevron when `onTap` is provided
- Does NOT render chevron when `onTap` is null
- `MmListSection` renders internal dividers between children

### `test/core/widgets/mm_text_field_test.dart`
- Renders label text
- Shows error message when validator fires
- `onChanged` fires on text input

### `test/core/widgets/mm_eyebrow_test.dart`
- Renders text in ALL CAPS with correct style

## Setup Notes

All tests use `flutter_test` + `WidgetTester`. No Firebase, no Riverpod mocks needed — all mm_* widgets are pure presentational.

Wrap tests in `MaterialApp(home: Scaffold(body: ...))` to provide Material context.
