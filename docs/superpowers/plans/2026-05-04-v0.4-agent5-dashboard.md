### Task 3 — `_StoreSetupCard` conditional

Wrap the `_StoreSetupCard` call in a condition:

```dart
// BEFORE:
if (role == 'coordinator') ...[
  _StoreSetupCard(ref: ref),
  const SizedBox(height: DesignTokens.spaceMd),
  ...

// AFTER:
if (role == 'coordinator') ...[
  Builder(
    builder: (_) {
      final zoneState = ref.watch(zoneMapNotifierProvider);
      final store = zoneState.storeData;
      final needsSetup = store == null ||
          store.widthFt == null ||
          store.depthFt == null ||
          (store.entranceJson == null || store.entranceJson!.isEmpty);
      if (needsSetup) ...[
        _StoreSetupCard(ref: ref),
        const SizedBox(height: DesignTokens.spaceMd),
      ],
      return const SizedBox.shrink();
    },
  ),
  ...
```

Wait — `_StoreSetupCard` already watches `zoneMapNotifierProvider` internally. To avoid double-watching, read the condition at the call site using a `Consumer` or pass the data in. Better approach: make `_StoreSetupCard` return `const SizedBox.shrink()` when setup is complete by checking internally and let the outer code call it unconditionally. Actually simpler: just check `hasDims && hasEntrance` at call site using a `Consumer`:

```dart
Consumer(
  builder: (context, ref, _) {
    final store = ref.watch(zoneMapNotifierProvider).storeData;
    final hasDims = store?.widthFt != null && store?.depthFt != null;
    final hasEntrance = store?.entranceJson != null && store!.entranceJson!.isNotEmpty;
    if (!hasDims || !hasEntrance) {
      return Column(
        children: [
          _StoreSetupCard(ref: ref),
          const SizedBox(height: DesignTokens.spaceMd),
        ],
      );
    }
    return const SizedBox.shrink();
  },
),
```
