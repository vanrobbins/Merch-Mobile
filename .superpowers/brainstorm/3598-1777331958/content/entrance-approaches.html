A — Canvas drag

Entrance lives on the Zone Map canvas. Dedicated edit mode: drag the gap to slide along the wall, drag endpoints to resize. Tap a different wall to move it. Most consistent with zone/fixture interaction.

Pros

  • Same feel as zone drag
  • Visual, spatial, no sliders
  • Removes dashboard clutter

Cons

  • More implementation work

B — Live preview in sheet

Keep the existing Dashboard bottom sheet but add a live mini store-boundary preview at the top. Sliders and chips remain — the preview just updates in real-time to show where the entrance lands.

Pros

  • Minimal code change
  • Visual feedback added

Cons

  • Still abstract sliders
  • Still lives on dashboard
  • Not consistent with canvas

No entrance set — tap any wall on the canvas to place

C — Tap-to-place on canvas

Tap any point on the store wall to place the entrance there instantly, at a default width. Once placed, tap to select and get a small popover with width +/− and remove controls. No sliders at all.

Pros

  • Simplest interaction
  • No modal/sheet needed

Cons

  • Width control is awkward
  • Hard to hit exact position
