Fixture-type resize behaviour

Edge handles (B) — but each fixture type constrains which axes make sense. Does this match how you think about them?

W

Wall fixture / Shelf

Mounted against a wall — depth is fixed (usually 1–2 ft and never changed). Only width is resizable. Show left + right edge handles only. Top/bottom handles hidden.

R

Rack (clothes / merchandise)

Free-standing — both width and depth are meaningful. All 4 edge handles active. Width = how many items hang across. Depth = aisle clearance. Rotation available via long-press.

T

Table / Display table

Free-standing surface — width and depth both matter for product spread. All 4 edge handles active, same as rack. But table aspect ratio is often closer to square, so depth drag feels more useful here than on a rack.

P

Partition / Wall divider

Thin structural element — width only (same logic as a wall fixture). Depth is always 0.5 ft or similar. Only left + right handles shown. Rotation via long-press matters a lot here (horizontal vs vertical wall).

Proposed rule: wall + partition = width-only handles; rack + table = all 4 handles. Rotation stays on long-press action sheet for all types. Does this match how you think about them — any types missing or constraints wrong?
