Store size and grid

Should the canvas have defined physical dimensions, or be open-ended?

A

Defined store dimensions (recommended)

Coordinator sets store width × depth in feet (e.g. 60ft × 40ft) in a one-time setup step. The canvas draws a bordered store boundary rectangle at that size, with a ft grid inside. Zones must fit within the boundary. Fixtures outside a zone but inside the store are allowed.

Store: 60 × 40 ft

Store dimensions saved in a new stores.width_ft / depth_ft column. One-time setup, editable from store settings.

B

Open canvas — grid only, no boundary

No store size defined. The grid is purely a visual reference for spacing. Canvas is infinite — zones can go anywhere. Simpler to implement, but you lose the ability to know if zones fit in your real store.

Grid: 3ft squares

I recommend A — the store boundary makes placement meaningful. Requires adding width_ft / depth_ft to the stores table, which is a small schema change.
