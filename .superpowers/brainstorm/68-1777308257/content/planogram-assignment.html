Planogram assignment on fixtures

Fixtures already have a planogram_id FK — we need the UI to assign it. Where and how?

A

Inline badge on fixture (recommended)

Each fixture renders a small badge in its corner. Unassigned = grey "—" chip. Assigned = accent-colored planogram name chip. Tapping the badge opens a picker sheet to assign/change/remove. The fixture itself is still tap-to-select / drag-to-move.

B

Long-press fixture → action sheet

Fixture shows a planogram badge (read-only indicator). Long-pressing the fixture opens an action sheet with options: Label, Assign Planogram, Rotate, Delete. Same gesture used today for labeling already exists.

C

Tap to select → properties panel slides up

Selecting a fixture slides up a mini panel from the bottom showing fixture name, dimensions, and planogram slot with an Edit button. No long-press needed — selection = editing intent.

I recommend A — the badge is always visible so you always know assignment status at a glance, and the tap target is separate from drag/select so there's no gesture conflict.
